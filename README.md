# minyon

A modern React dashboard application built with TypeScript, Vite, and Tailwind CSS.

[Edit in StackBlitz next generation editor ⚡️](https://stackblitz.com/~/github.com/myblackbeanca/minyon)

## Development

```bash
# Install dependencies
npm install

# Run development server
npm run dev

# Build for production
npm run build

# Preview production build
npm run preview
```

## Claude Code Infrastructure

This project includes Claude Code infrastructure for AI-assisted development:

- **Hooks**: Auto-activation of development guidelines
- **Skills**: React/TypeScript best practices
- **Agents**: Task automation (coming soon)

See [.claude/README.md](.claude/README.md) for details or [.claude/INTEGRATION_GUIDE.md](.claude/INTEGRATION_GUIDE.md) for setup instructions.

### Quick Start with Claude Code

1. Install dependencies: `npm install -D tsx`
2. Make hooks executable: `chmod +x .claude/hooks/*.sh`
3. Try: "Create a new React component" - watch skills auto-activate!
